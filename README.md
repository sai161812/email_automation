# Simple Email Automation (Python)

This script sends emails automatically using Python.

---

## 📦 Requirements

* Python installed
* Install the **yagmail** library

---

## 🔐 Setup (Important)

1. Go to your Google account
2. Turn ON **2-Step Verification (2FA)**
3. Search **App Passwords**
4. Generate a password
5. Use that password in your script

---

## 🧠 How it works

* You provide a list of email addresses
* The script loops through each one
* Sends the same email to all recipients

---

## ▶️ Run

Run the Python file normally from your terminal or IDE.

---

## ⚠️ Notes

* Use an **App Password**, not your real password
* Avoid sending too many emails at once (Gmail has limits)
* Add delay if sending bulk emails

---

## ✅ Output

Emails will be sent successfully to all addresses in your list.
